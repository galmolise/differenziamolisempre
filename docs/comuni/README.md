# Dati per Comune

Aggiungere una cartella `identificativo-comune/dati.json` per ciascun nuovo Comune e inserire una voce nel file `index.json` con `id`, `nome` e `file` (relativo alla cartella `docs`).

La versione corrente dell'editor apre automaticamente Pietracatella. In un hosting HTTP può caricare anche gli altri Comuni elencati nel manifest, purché siano presenti e compatibili con lo schema supportato. Nell'app iOS il Comune rimane fisso: l'editor non rende automaticamente multi-comune l'app.
